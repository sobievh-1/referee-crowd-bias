# referee-crowd-bias

Do crowds make Premier League referees penalise away teams more harshly?

This project uses matches played without fans during COVID-19 (the 2019/20 restart and most of 2020/21)
as a natural experiment to compare referee decisions with and without a crowd.

**Status:** work in progress.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
